# DJ Challe – hjemmeside

Statisk hjemmeside bygget med HTML og CSS. Der kræves ingen buildproces eller pakkeinstallation.

## Filer

- `index.html` – hjemmeside
- `tak.html` – bekræftelsesside
- `styles.css` – design og layout
- `images/challe.jpg` – forsidebillede
- `favicon.svg` – ikon til browserfanen

## Lokal visning

Åbn `index.html` i en browser.

## Udgivelse

Projektet kan udgives som et statisk site på Vercel uden build command og med projektroden som output. Inden lancering skal kontaktoplysninger, priser, område, musikeksempler og bookingformular tilføjes.
