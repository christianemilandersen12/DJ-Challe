# DJ Challe – hjemmeside

Static HTML and CSS website. English is the default language, with a button to switch to Danish. No build process or package installation is required.

## Filer

- `index.html` – hjemmeside
- `tak.html` – bekræftelsesside
- `styles.css` – styling and layout
- `script.js` – language toggle
- `images/challe.jpg` – forsidebillede
- `favicon.svg` – ikon til browserfanen

## Lokal visning

Open `index.html` in a browser.

## Udgivelse

The site can be deployed to Vercel as a static site with no build command and the project root as output. Before launch, add the contact details, pricing, service area, music samples, and booking form.
